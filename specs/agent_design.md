# Agent Design

## 1. Context Agent

Responsável por entender a fala inicial do estudante e extrair temas significativos.

Entrada:
- Nome
- Idioma
- Resposta aberta sobre a comunidade

Saída:
- Temas
- Palavras candidatas
- Contexto resumido

## 2. Generative Word Agent

Seleciona uma palavra geradora com base em:
- Relevância para o aluno
- Simplicidade silábica
- Potencial pedagógico
- Segurança

## 3. Linguistic Agent

Gera:
- Sílabas
- Família silábica
- Exemplos
- Atividades de combinação

## 4. Pedagogical Agent

Adapta dificuldade com base em:
- Acertos
- Erros
- Tentativas
- Tempo de resposta

## 5. Multimodal Agent

Prepara:
- Texto
- Áudio
- Imagem
- Prompts visuais

## 6. Safety & Trust Agent

Valida:
- Adequação do conteúdo
- Explicabilidade
- Transparência da escolha pedagógica
